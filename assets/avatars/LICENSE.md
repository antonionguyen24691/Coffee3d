# Avatar source

`asian-casual.glb` and `asian-casual-woman.glb` were exported from [Ara 3D Gen](https://github.com/olatunde85/3d-gen), using its Asian male and female bodies, casual outfits, game rig, and Idle, Walk, Run, Sit idle (chair), and Wave animations.

`cyberpunk.glb` was exported from the same tool using its Cyberpunk Hacker character preset and the same five animation clips.

Ara identifies its MakeHuman character assets as CC0 1.0 and its code as MIT. The project's licensing notes state that some motion-capture clips originate from the CMU Graphics Lab Motion Capture Database and may be used commercially but not resold on their own. See [Ara's asset notice](https://github.com/olatunde85/3d-gen/blob/main/scripts/ASSETS_LICENSE.txt) and [project licensing](https://github.com/olatunde85/3d-gen#licensing).

The CMU Graphics Lab Motion Capture Database was created with funding from NSF EIA-0196217; the data used by Ara was obtained from https://mocap.cs.cmu.edu/.
