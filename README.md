# ☕ Cà Phê Online 3D – Quán cây xanh chill

Quán cà phê 3D nhiều người chơi: tạo nhân vật, gọi món, chat chung và nhắn riêng, tặng quà, đấu gối, nghe nhạc phong cách Việt, xem TV.

## Cài đặt
1. Dán cấu hình Firebase vào `index.html` (tìm dòng `DÁN CẤU HÌNH FIREBASE`).
2. Firebase: tạo **Realtime Database** (Singapore), dán `database.rules.json` vào tab **Rules** → Publish.
3. Firebase: **Authentication → Sign-in method → Anonymous → Enable**.
4. GitHub: **Settings → Pages → Deploy from a branch → main / (root)**.
5. Firebase: **Authentication → Settings → Authorized domains** → thêm `antonionguyen24691.github.io`.
